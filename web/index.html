Methodology

Technical details are available for users who want to inspect data contracts and evaluation safeguards.

  • Delivery truth comes from the IPL CSV loaded into SQLite.
  • Enrichment metadata (teams, matches, assets) is separate and provenance-aware.
  • Prediction is deterministic and built only from pre-ball knowledge.
  • Temporal evaluation and leakage protections are retained.
  • Ask MatchGenome uses validated query plans and read-only SQL execution.
